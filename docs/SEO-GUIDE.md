# Fieldnotes Technical & Content SEO Guide

A sustainable, ethical blueprint for long-term organic growth without algorithmic tricks or automated spam.

---

## 1. Principles of Organic Growth

Fieldnotes focuses on **editorial quality, information gain, and technical precision**. Search engines reward pages that comprehensively answer real human questions and demonstrate authentic first-hand experience (E-E-A-T).

---

## 2. Technical SEO Checklist

Fieldnotes handles key technical SEO requirements at build time:

1. **Automated XML Sitemap**: Generated by `@astrojs/sitemap` at `dist/sitemap-index.xml`.
2. **Canonical Links**: Automatically computed per-page to prevent duplicate content flags across deploy URLs and staging builds.
3. **Structured Data (JSON-LD)**:
   - `WebSite` schema on the homepage.
   - `BlogPosting` schema on all articles containing headline, datePublished, dateModified, and author attribution.
4. **Social Graph Meta Tags**: Full Open Graph and Twitter Card tags with pre-rendered social cards.
5. **Fast Static Generation**: 0kB client-side JS overhead on static content; instant First Contentful Paint (FCP).

---

## 3. Search Intent & Topic Selection

- **Answer Real Questions**: Research common questions from developer forums, GitHub issues, and community discussions. Note where existing tutorials are obsolete, vague, or incomplete.
- **Unique Angle & Information Gain**: Before drafting, ask: *What can this article explain that the first three search results fail to cover?* Include benchmarks, edge cases, configuration snippets, or architecture diagrams.
- **Avoid Keyword Stuffing**: Write naturally for intelligent readers. Use technical terminology accurately instead of forcing unnatural synonym repetitions.

---

## 4. On-Page Structure & Formatting

- **Descriptive Titles (50–65 characters)**: Front-load the primary subject and outcome (e.g., `Deploying Astro 7 to GitHub Pages with Pagefind Search`).
- **Unique Meta Descriptions (120–160 characters)**: Clearly outline what the reader will learn.
- **Headings (H2 / H3)**: Ensure headings describe the subsection rather than using vague words like "Details" or "More Information".
- **Internal Linking**: Link to at least 2–3 related articles within the publication to assist crawlers and keep readers engaged.

---

## 5. Image SEO

- **Descriptive Alt Text**: Describe the contents and technical relevance of charts, diagrams, and screenshots.
- **Optimized Formats**: Use SVG for vector diagrams and icons; WebP/PNG for screenshots.
- **Meaningful Filenames**: Use lowercase kebab-case filenames (e.g., `github-pages-workflow-diagram.svg` instead of `IMG_9021.png`).

---

## 6. Maintenance & Content Freshness

- Revisit high-traffic articles quarterly to update dependency versions, deprecation warnings, and screenshots.
- Update `modDatetime` in the frontmatter whenever making significant factual edits; search engines index updated dates and reflect freshness in search snippets.

---

## 7. Webmaster Search Console Setup

### Google Search Console
1. Visit [Google Search Console](https://search.google.com/search-console).
2. Add your property (e.g. `https://dion-verse.github.io/fieldnotes/` or custom domain).
3. Choose the **HTML tag** verification method.
4. Copy the verification code and set `googleVerification: "YOUR_CODE"` in `astro-paper.config.ts`, or add `PUBLIC_GOOGLE_SITE_VERIFICATION="YOUR_CODE"` in your GitHub repository secrets.
5. Submit your sitemap: `https://<your-domain>/sitemap-index.xml`.

### Bing Webmaster Tools
1. Visit [Bing Webmaster Tools](https://www.bing.com/webmasters).
2. Sign in with GitHub or Microsoft.
3. Import your verified Google Search Console property or verify via the `<meta>` verification tag.
4. Submit your sitemap: `https://<your-domain>/sitemap-index.xml`.
